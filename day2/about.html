About QuickNotes

QuickNotes is a lightweight note-taking app for capturing ideas, tasks and reminders the moment they come to you. It keeps things simple so you can spend less time organising and more time doing.

How to use QuickNotes

  1. Open QuickNotes and click the "New note" button.
  2. Type a title and write your note in the text area.
  3. Press Save to store your note.
  4. Find your notes later from the list on the home page.

Features

  • Create notes instantly
  • Edit and delete notes at any time
  • Clean, distraction-free layout
  • Keyboard shortcuts for faster work

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + D Delete the current note
